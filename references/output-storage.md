# 保存目录与批次管理

仅在要把卡片写入本地文件时读取本规则。纯聊天中的草稿、讲解和自检无需询问保存位置。

## 用户配置

配置固定保存在 `~/.config/crash-flashcard/config.json`（`~` 为当前用户主目录），独立于 skill 安装位置和任务工作区。跨任务以实际配置文件为依据，不能只依赖对话记忆。

```json
{
  "output_root": "/absolute/path/to/flashcards"
}
```

首次制卡、配置中没有 `output_root` 时，询问一次：“卡片以后默认保存在哪个根目录？我会记住它，每批新建一个子文件夹；你也可以指定仅本次的位置。” 等待用户给出路径后再写文件，期间可以继续整理内容。不要自行选定永久目录。

- 用户回答默认根目录后，展开 `~`，将相对路径按当前任务工作区解析为绝对路径，展示解析后的路径，并创建需要的目录。确认目录可写后，把绝对路径写入配置；保留其他已有配置字段。配置不存在时创建父目录和文件。
- 已有有效配置时直接读取使用，无需重复询问。只有用户明确要求更改以后默认位置时，才更新 `output_root`。
- 用户在请求中指定本次保存位置时，它优先于配置，作为本批次的根目录；不改写持久配置。若尚未配置默认目录且用户已明确仅本次保存位置，本次直接使用，下一次无临时位置的制卡再询问默认目录。
- 配置损坏、根目录不可写或配置保存失败时，说明具体问题，让用户选择修复或提供替代路径；不静默回退到任务工作区。持久配置未成功写入时，明确说明尚未记住默认位置。

## 每批独立目录

在所选根目录下创建 `YYYY-MM-DD_HHMMSS_主题简称/`，使用本机当地时间。主题简称保留可读中文，替换路径分隔符及文件名非法字符，移除末尾空格或点，控制在约 40 个字符；无法提取时用 `知识卡片`。

创建目录时要求目录尚不存在；同名则追加 `-02`、`-03` 等编号再尝试，避免覆盖已有批次。把成功创建目录的绝对路径作为 `OUTPUT_DIR`。输出根目录和批次目录均放在 skill 安装目录之外。

本批次的 `manifest.json`、`intro.md`、`answer-key.md`、`review.md`、`quick-check/` 和 `explanation/` 全部放入该目录。最终交付给出可点击的批次目录链接。

新主题或新一批制卡创建新目录。明确修改或重渲染同一批卡片时沿用该批次目录；读取原 manifest 识别旧产物，移除本次已取消卡片对应的旧 PNG/SVG，保留用户其他文件，再执行输出校验。无法确定原批次位置时先定位原产物或询问，不把任意已有目录当作当前批次。
