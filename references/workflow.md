# 知识核对、费曼式带练与复习交付

## 知识核对与覆盖

先从用户目标确定本次完成的能力。示例：“解释事务隔离的作用，能辨别三种读异常”；边界或实现依赖要和结论放在一起。

先核对材料中与核心知识点相关的主张，明确呈现影响理解的错误与修正。有用户自述时，将每个独立主张对应到 `原述短引文 → 正确／部分正确／错误／无法判断 → 理由 → 纠正基线`。同类错误合并解释但保留全部主张映射。没有自述则直接整理主题，不假装做过诊断。

把以下适用要素串成完整知识单元：

- 定义与用途：是什么，解决什么问题。
- 机制或步骤：为什么成立，关键中间关系是什么。
- 前提与边界：成立需要什么，不适用于哪里。
- 例子与迁移：一个完整例子，换情境时依据什么判断。
- 易混点：与邻近概念的决定性区别。

必要前置知识先补，再明确回到原问题；范围外拓展只作简短定位。已经提出但未处理的核心疑问不能改名为拓展。纯事实与人文解释分别采用合适的关联或证据标准，不硬造机制、反例或唯一立场。

维护简短覆盖记录，草稿和收尾时展示即可：

| 问题／知识点 | 修正或必要条件 | 讲解卡 ID | 自检卡 ID | 状态／证据 |
|---|---|---|---|---|
| 具体内容 | 准确基线或待核验内容 | 对应 ID | 对应 ID | 已讲待检／真实回答结果 |

## 带练循环：仅在用户要求学习辅导时使用

1. **尝试解释。** 有基础时请用户用自己的话说明一个核心点；零基础或无法开口时先给最小讲解与完整例子。已有长自述直接进入核对。
2. **定位缺口。** 根据内容定位术语、机制、前提、边界或方法选择问题；不以口才、篇幅、自信或“懂了”作为通过证据。
3. **定点补学。** 正确处简短确认，错误处解释为什么，补一个必要例子或前提。只修当前最关键缺口。
4. **重新解释。** 让用户脱离上文，用自己的话重讲修补点；看过答案或靠提示完成，先标“有支持完成”，换等价新情境再检查。
5. **整合。** 小单元连起来后，让用户整体解释一次，避免只会零散片段。合格的一次解释可以覆盖多个检查维度，不重复加考。

交互时每条消息只留下一个待回答任务。普通讲解可从约 200–400 汉字起步，按实际负担和必要推理调整。可接受短句、箭头、简单图或口述转写，不要求整齐长作文。用户说“直接给答案”时直接给，并如实记录尚未独立检验。

### 提问如何符合费曼法

按当前缺口选一种提问；这不是需要一次问完的清单。

| 目标 | 可用题干 |
|---|---|
| 朴素解释 | “把这个概念讲给第一次接触它的人，说明它解决什么问题。” |
| 机制 | “这个结论为什么成立？请讲清最关键的中间一步。” |
| 应用 | “换成这个新情境，请教我怎样判断。” |
| 边界 | “这段待判断的解释哪里有问题？请修正并说明理由。” |
| 整合 | “请把这几个知识点连成一段完整解释。” |

新手不是儿童，不必故意幼稚化。允许准确术语，但要求知道它的含义。题干不预先填出被考查的因果关系，不用换一个句式照抄答案代替回忆。

### 按缺口选择其他方法

- **不会开始**：先示范完整例题，说明每步理由，再给半成品或相似新题，逐渐减少提示。
- **记不住**：先闭卷尝试，再核对与纠错；以后隔一段时间复习同一核心关系。
- **相近概念混淆**：用一组只改变关键条件的对照例子。分别能完成后再混合已学题，让用户自行选择方法；混合题替换现有自检题，不额外堆数量。
- **同错反复**：换表示、退回前置知识或缩小单元，区分“方法选错”和“执行错误”；不重复施压。

这些方法服务于缺口，不要求每个单元全部执行。类比给出对应关系与失效处；数学或技术细节仍需必要推导、条件和可检查步骤。

### ADHD 友好的恢复方式

下一步明确，页面短段可扫描，重点克制。用户说“太多／走神”时缩成一个结论、一个例子和一个小任务；将剩余范围记下来。适合时可建议活动休息，时长依据个人状态，不使用统一最佳分钟数。

“暂停”优先于继续教学，给四行续学卡：目标、已通过点、当前缺口、回来后的下一题。回来时从此处恢复；只依据当前可访问的记录，不宣称跨会话永久记住。

## 交付与复习包

### 题目与讲解分开

quick-check 图片用于作答；explanation 图片用于补学。默认一个小主题约 4–6 个高覆盖检验任务，简单主题更少、较大主题按单元增加，不能为凑数量重复问同一件事。选择定义、关键机制、迁移／边界和整合中实际适用的任务。

避免标题直接给方法标签：如果要检验“该用平均数还是中位数”，题目应给情境而非写“用中位数解答”。同一批次的讲解组也可能提示答案，交付时说明先做题目组，再看讲解组。

### answer-key.md：逐题核对

以 manifest 的 `answer_key` 为答案基线，按 quick-check ID 覆盖全部作答栏，保持语义、数据、条件与作答栏对应一致，不生成相互冲突的第二套答案。

```text
## qc-001：卡片标题
对应目标／讲解卡：...
作答栏 1 答案：最短但充分的答案
关键理由或步骤：...
核对：□ 核心关系 □ 必要条件 □ 结果／单位（按题适用）
常见错法／修补位置：只在有帮助时列出
```

每道题都给答案、理由和核对点，可合并成短段。开放题接受语义等价解释，列出必要条件，不能按逐字一致评分。争议性内容核对证据与推论，不捏造唯一立场。

初始答案包不为每题再追加一道未配答案的题。实际修补时再给等价新题；批量交付新题时也配齐答案。核对时区分核心错误、漏条件、有提示和独立完成；关键错误不能靠平均分抵消。

### review.md：快速复习与恢复

```text
# 本次主题与范围
一句话核心：...
核心关系／完整流程：...
代表例子：输入 → 关键一步 → 结果
关键边界／易混点：...
卡片映射：知识点 → explanation ID → quick-check ID
掌握记录：仅按实际回答填写；未作答写“已讲待检”
未闭环项：待核验事实／待修补能力；没有则说明本次范围已覆盖
下次闭卷任务：具体卡片 ID 或整体解释任务
建议复习：次日、几天后、一周后可作为可调整起点；未创建提醒
```

速记部分以约一分钟可扫完为目标，多主题分单元，保留整体关系而不重复整套讲解。只有实际出现的错误才能写成“个人易错点”；一般误区另行标注。

### 掌握与复习规则

- `已讲待检`：解释或卡片已交付，尚无回答证据。
- `待修补`：核心错误、遗漏必需条件或无法作答。
- `有支持完成`：看过答案、靠提示或步骤支架完成。
- `当场独立通过`：在约定闭卷条件下用自己的话解释或应用正确；不确定是否闭卷时，写“作答正确，闭卷未确认”。
- `延迟通过`：隔一段时间后实际无提示通过，不等于永久掌握。

复习先回忆再查答案。忘记则补学并缩短间隔，稳定独立答对再延长；无需每轮追问信心评分。具体日期间隔是可调整默认值，不声称精确预测个人遗忘。只有用户明确要求且工具支持时才创建提醒。

## 简介文案

文案简短说明主题和复习用途，可提示收藏复习；不添加未经核实的面试频率、经验、效果承诺或卡片外事实。只生成本地文案，不自动发送或发布。
