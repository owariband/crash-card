## q-range · 换个区间，你会怎么查？

查询 22 ≤ k ≤ 55：从根开始，说明访问哪些叶子、返回哪些键，以及在哪里停止、为什么。

### 题目背景

- root · **根：30 | 50**
- p1 · **P1**：10, 20
- p2 · **P2**：30, 40
- p3 · **P3**：50, 60

连接：
- root → p1：<30
- root → p2：30–49
- root → p3：≥50

键为互异整数；有序叶层：P1 → P2 → P3。箭头表示相邻叶子的链接，区间含两端。

#### 结果：30、40、50

访问路径：根 → P1 → P2 → P3。

#### 为什么这样走

22 < 30，先到 P1；10、20 都小于下界。沿叶层到 P2，返回 30、40，再到 P3 返回 50。遇到 60 > 55 就停止：后续键更大，也不符合区间。

#### 结构起了什么作用

根只负责路由；定位后利用叶层的有序链接继续扫描，无需为每个结果重新从根查找。

### 核对标准

- start · 必要：说明先到 P1，再沿叶层向后查。
- result-stop · 必要：结果为 30、40、50；用有序性解释停止。

### 需要修正的错误

- 认为下界 22 不存在就没有结果。
- 直接把内部节点的分隔键当作返回记录。
